# 🎓 RUET CSE Academic Repository

Welcome to my comprehensive academic archive for the **Computer Science and Engineering (CSE)** program at **Rajshahi University of Engineering & Technology (RUET)**. This repository contains all of my lab works, assignments, sessional projects, and other academic contributions from the 1st year to the final year.

---

## 📚 Curriculum Overview

The RUET CSE undergraduate program is divided into **8 semesters** (4 years), including both **theory** and **sessional** (lab/project) courses.

## 🧭 Branch Structure

Each semester has its own dedicated branch:

| Semester                   | Branch Name               |
|----------------------------|---------------------------|
| 1st Year - Odd Semester    | `1st-Year-Odd-sem`        |
| 1st Year - Even Semester   | `1st-Year-Even-sem`       |
| 2nd Year - Odd Semester    | `2nd-Year-Odd-sem`        |
| 2nd Year - Even Semester   | `2nd-Year-Even-sem`       |
| 3rd Year - Odd Semester    | `3rd-Year-Odd-sem`        |
| 3rd Year - Even Semester   | `3rd-Year-Even-sem`       |
| 4th Year - Odd Semester    | `4th-Year-Odd-sem`        |
| 4th Year - Even Semester   | `4th-Year-Even-sem`       |

To view the code of any semester:

```bash
git checkout <branch-name>
````
